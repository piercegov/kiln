# Kiln docs site

The documentation site: [VitePress](https://vitepress.dev) for the guides, and
[TypeDoc](https://typedoc.org) (with `typedoc-plugin-markdown`) for the API reference, generated
from the JSDoc in `packages/kiln/src`. It is a standalone package, outside the Bun workspace, so its
dependencies don't touch the game packages.

```bash
cd docs
bun install
bun run dev        # regenerate api/ and serve at http://localhost:5173
bun run build      # regenerate api/ and build to .vitepress/dist
bun run preview    # serve the build
```

- `guide/`, `concepts/`, `plugins/`, `testing/`, `reference/`: hand-written pages.
- `api/`: generated by `bun run api`; not committed.
- `design.md`: implementation notes against the design doc.
- `typedoc.json`, `typedoc-plugin-kiln.mjs`: the API reference's entry points and module names.

The build also writes `llms.txt`, `llms-full.txt` and a `.md` copy of every page
([vitepress-plugin-llms](https://github.com/okineadev/vitepress-plugin-llms)), so agents can read the
site as plain text.

`packages/kiln/docs/agents-guide.md` is a separate, denser text: the guide `kiln new` and `kiln docs`
put at the top of every game's `AGENTS.md`. When an API changes, update both.
